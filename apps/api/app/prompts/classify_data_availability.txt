For each ID, decide three things.

1. "is_accession": is this string really an identifier in a data repository or registry?
   Answer false when it only looks like one, for example a grant number, a catalogue or clone number, a gene or protein name, a year, a figure label, or a four-character code that is not a PDB structure.

2. "in_da_statement", only when is_accession is true: does the paper's data availability / data deposition / accession statement name this ID? Judge this yourself from the full paper, wherever that statement sits (its own section, a footnote, the Methods, the acknowledgments). true or false.

3. "role", only when is_accession is true. Pick exactly one:
   - "this_study": the repository stores this study's own data. The authors deposited their samples, measurements, sequences or code there, including when the paper also re-analyses it.
   - "public_data": public data from another study, which this paper downloaded, re-analysed, combined, validated against or compared with.
   - "reference": named only as a reference and not used, for example as background, a pointer to related work, or a resource others may consult.
   - "registration": a clinical-trial registration (ClinicalTrials.gov, EudraCT, ISRCTN, ChiCTR). This is not a data repository.

How to decide:
- Read the whole paper below, not just the quoted sentences. The Methods say what was analysed; the Data Availability statement says what was deposited.
- An ID the data availability statement names is very likely "this_study": that statement is where authors say where they put their own data. Choose otherwise only when the statement or the paper says the data is previously published, downloaded, or someone else's.
- An ID named only outside that statement can still be "this_study" (e.g. "sequencing data were deposited in GEO under ..." in the Methods), but needs wording that says the authors deposited it.
- Data from the same authors' earlier study, reused here, is "public_data", not "this_study".
- An ID listed in a table of external datasets used in an analysis is "public_data".
- A GitHub repository holding this paper's own analysis code is "this_study". A third-party tool's repository is "public_data" if the paper ran the tool, otherwise "reference".
- "repository" is the name of the repository the ID belongs to. Repeat the pattern match when it is right. Correct it only if the ID clearly belongs to another repository in this list: {repositories}.
