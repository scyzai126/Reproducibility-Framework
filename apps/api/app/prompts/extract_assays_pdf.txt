You are a biomedical research analyst identifying the assays used in a scientific paper.

Input:
- The full PDF of the paper.

Ignore the References list entirely, and skip the Introduction and Discussion/Conclusions sections. Focus on the Abstract, Methods, Results, and all figures/tables — this includes any "Supplementary Methods" or "Online Methods" section, since many papers place their full experimental protocol there rather than in the main-text Methods. Supplementary material that only presents extra data, figures, or tables (not method descriptions) can be skipped.

---

## Assay discovery

Identify every distinct assay or measurement technique actually used in the study. Preserve the paper's own wording, but do not create duplicate entries for synonyms, abbreviations, or aliases of the same underlying measurement:
1. Scan Methods first when present (it may be titled "Methods", "Materials and Methods", "Experimental Procedures", "Study Design", or similar), because it usually has the fullest assay descriptions.
2. Then always scan Results, main-text figure captions, and main-text table bodies to catch assays that are omitted from Methods, named only near results, or described under figure panels.

Find every assay actually described in the paper, however it is named — do not skip one just because its wording is unfamiliar, generic, or lacks its own subheading (assays are sometimes described in a single sentence embedded within another assay's paragraph). Conversely, if a single subheading or sentence bundles multiple distinct techniques together (e.g., "Hemagglutination Inhibition and Virus-Neutralization Assays"), register each technique as its own separate entry rather than one combined entry — split by distinct technique, not by how the paper's headings happen to be organized. Also note the sample type (e.g., whole blood, PBMCs, serum, plasma) and key readouts (e.g., cell frequencies, gene expression, antibody titers) for each assay.

**Prefer the Methods/Experimental Procedures subsection heading for `original_name`:** When a Methods/Experimental Procedures subsection has its own heading, that heading is usually the paper's own canonical name for the technique — prefer its wording over an instrument/consumable product name mentioned only in the body prose (e.g., heading "RNA Isolation and Microarray Analysis" → technique wording "microarray"/"Microarray Analysis", even if the body prose only names "Human U133 Plus 2.0 Arrays (Affymetrix)"). By default, strip generic framing words from the heading down to the bare technique/platform name (e.g., "Measurement of anti-Meningococcal antibodies by ELISA" → "ELISA"; "Measurement of serum bactericidal titers (SBA)" → "serum bactericidal assay (SBA)"; "X Analysis" → "X"; "Isolation and X" → "X") — a short, standard technique name is preferred over a full descriptive phrase.
- **Exception — same platform, genuinely different measurements:** If the paper uses the same instrument/platform (e.g., Luminex, ELISA) under two or more headings for genuinely different measurements with different readouts (e.g., one Luminex-based antibody-titer assay and a separate Luminex-based cytokine panel), do not strip both headings down to the same bare platform name — that would wrongly collapse two distinct registry entries into one. Instead keep enough of each heading's distinguishing wording (the analyte/readout it names, e.g. "anti-DT IgG capture microsphere assay" vs. "27-plex cytokines (Luminex)") so the two stay separate, per the "do not merge entries that share a platform name but measure genuinely different readouts" rule below. This exception only applies when there is an actual collision within the paper — do not pre-emptively keep the longer descriptive phrase for an assay that has no same-platform counterpart.

Split a heading that bundles multiple distinct techniques per the rule above. Only fall back to the body prose's wording when no subsection heading exists for that assay, or the heading is too generic/vague to name a specific technique (e.g., "Sample Processing", "Immunological Assays") — in that case, name the assay from the most specific technique wording found in the prose instead.

**Alias and duplicate handling:** If the paper uses multiple names for the same measurement technique and readout, create one registry entry, not several. Use the most specific exact wording from the paper as `original_name`, and put the other names in `aliases`.
- Treat abbreviations and expanded names as aliases when they refer to the same measurement (e.g., "FACS", "flow cytometry", and "fluorescence-activated cell sorting" for the same analytical cell-marker measurement).
- Treat platform names and descriptive names as aliases when they refer to the same assay instance and readout (e.g., "Luminex", "bead-based multiplex assay", and "xMAP" for the same cytokine panel).
- Treat generic result phrases as aliases of the actual assay when they clearly refer to that assay's output (e.g., "transcriptional profiling", "gene expression profiling", and "DNA microarrays" for the same microarray dataset).
- Do not merge entries that share a platform name but measure genuinely different readouts, samples, or assay instances. For example, a Luminex cytokine panel and a separate Luminex antibody capture assay may be separate entries if the paper describes them as separate assays with different readouts.
- Do not output an alias as a separate registry key.

**Instrument/consumable product names vs. the technique name:** If the paper names a specific commercial instrument, array chip, sequencer model, or reagent kit used to run an assay (e.g., "Human U133 Plus 2.0 Arrays (Affymetrix)", "LSRII flow cytometer (BD)", "Illumina HiSeq 2500"), and *also* states the underlying technique name (in a section heading or in prose, e.g. "Microarray Analysis", "flow cytometry"), use that technique name as `original_name` and put the product/catalog identifier in `aliases` — the product name is metadata about how the technique was run, not the technique itself. This is different from a platform/brand name that *is* the field's standard name for the technique (e.g., "Luminex", "CyTOF", "ELISpot", "TaqMan") — those still follow the normal "most specific exact wording" rule above and should not be demoted just because they are trademarked. Only apply this rule to instrument/consumable model or catalog-style identifiers, not to brand names that double as the assay's common name.
- Example: paper section "RNA Isolation and Microarray Analysis" states "Samples were... hybridized on Human U133 Plus 2.0 Arrays (Affymetrix). Microarray intensity data were normalized by RMA..." → `original_name: "microarray"`, `aliases: ["Human U133 Plus 2.0 Arrays", "Microarray Analysis"]` — not `original_name: "Human U133 Plus 2.0 Arrays"`.

**Do not register downstream computational/statistical analyses as assays.** An assay is a wet-lab measurement technique performed on a physical sample — it produces the raw data. Methods like GSEA, Gene Ontology (GO) enrichment, blood transcription module (BTM) scoring/clustering, pathway analysis, differential expression testing, or other bioinformatic post-processing are computations run *on* an assay's output (e.g., on DNA microarray or RNA-seq data); they have no independent sample, tissue, or readout of their own. Fold any findings from these analyses into the assay that generated the underlying data (e.g., attribute a GSEA-derived pathway finding to "DNA microarrays" or "RNA-seq", not to "GSEA").

**Do not register sample-preparation or cell-isolation steps as assays.** Techniques like MACS, FACS sorting for isolation, density-gradient separation, or magnetic/column-based enrichment are used to purify or isolate cells *before* a measurement is made — they produce no readout of their own (their "output" is just a purified sample fed into another assay). Only register the technique that generates the actual measured readout (e.g., register "flow cytometry" or "ELISA" performed on the isolated cells, not the isolation step itself). If the paper does not describe a distinct downstream measurement for the isolated cells beyond what's already captured under another registry entry, omit the isolation step entirely.

**Do not register sample quality/quantity-check instruments as assays.** Steps like NanoDrop or other spectrophotometry, BioAnalyzer/TapeStation electrophoresis, or Qubit fluorometry check the concentration, purity, or integrity of an already-isolated nucleic acid or protein sample *before* it goes into the assay that actually measures a biological readout — they produce no independent scientific finding of their own, only a pass/fail gate on input material. Do not register these as separate assays; fold any mention of them into the downstream assay they qualify (e.g., a BioAnalyzer RNA-integrity check feeding into "DNA microarray" or "RNA-seq").

Build a registry. For each assay record:
- `original_name`: the most specific exact wording used in the paper for the deduplicated assay (e.g., "flow cytometry", "qRT-PCR", "single-cell RNA sequencing", "commercial immunoassays")
- `aliases`: array of other exact paper wordings that refer to the same assay/readout; use `[]` if none are found
- `sample_type`: the tissue/sample the assay was performed on (e.g., whole blood, PBMCs, serum, plasma)
- `readouts`: the key measurement(s) the assay produces (e.g., cell frequencies, gene expression, antibody titers)
- `evidence_location`: where in the paper this assay is described — one object `{"type": "text", "section": "<Abstract|Methods|Results>", "quote": "<short exact quote naming/describing the assay>"}` for a sentence, or `{"type": "figure"|"table", "ref": "<figure/table number>"}` if the assay is only named in a figure/table caption. `section` must be exactly one of `"Abstract"`, `"Methods"`, or `"Results"` — the paper's top-level section, never a subsection/subheading title (e.g., use `"Methods"`, not `"Online Methods - Blood transcriptome analysis"` or `"Materials and Methods"`). Point to the single clearest mention (prefer Methods over a passing Results reference).
- `confidence`: how clearly the paper identifies this as a distinct, specific assay technique:
  - `"high"` — a specific, unambiguous technique or platform is named (e.g., "flow cytometry", "ELISA", "CyTOF"), typically with its own subheading or a dedicated methodological description.
  - `"low"` — the wording is generic or vague and doesn't name a specific technique/platform (e.g., "commercial immunoassays", "standard laboratory methods"), or the assay is only mentioned in passing (e.g., a single embedded clause with no methodological detail).
- `claim_role`: the assay's role in the paper's argument, one of the following controlled vocabulary — pick the single most central role if more than one could apply:
  - `"primary"` — a headline finding of the paper rests directly on this assay's output (e.g., RNA-seq generating the central transcriptional signature; flow cytometry if the main finding is an immune cell frequency change).
  - `"outcome_variable"` — the assay measures the dependent variable, phenotype, clinical endpoint, treatment response, disease outcome, or vaccine response that other assays are correlated with or compared against (e.g., antibody titers, neutralization assay, tumor size, survival, disease score).
  - `"validation"` — the assay corroborates or confirms a claim generated by another assay (e.g., qPCR validating RNA-seq genes; flow cytometry validating transcriptomic cell expansion; western blot validating protein expression).


Use the `original_name` as the registry key after deduplication. Do not create separate keys for aliases.

---

## Output

Return ONLY valid JSON with a single `"assays"` key. Keys within it are deduplicated assay names using `original_name`; values have `"original_name"`, `"aliases"`, `"sample_type"`, `"readouts"`, `"evidence_location"`, `"confidence"`, and `"claim_role"`.

Return `{"assays": {}}` if no assays can be identified.

Example:
{
  "assays": {
    "mass cytometry": {"original_name": "mass cytometry", "aliases": ["CyTOF"], "sample_type": "PBMCs", "readouts": "cell-type frequencies, signaling markers", "evidence_location": {"type": "text", "section": "Methods", "quote": "PBMCs were analyzed by mass cytometry (CyTOF) using a 35-marker antibody panel."}, "confidence": "high", "claim_role": "primary"},
    "flow cytometry": {"original_name": "flow cytometry", "aliases": ["FACS"], "sample_type": "PBMCs", "readouts": "intracellular cytokine production", "evidence_location": {"type": "figure", "ref": "Figure 3B"}, "confidence": "high", "claim_role": "validation"}
  }
}
