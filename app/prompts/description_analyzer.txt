You are a biomedical research analyst. Given descriptions of participant groups from a scientific publication, extract structured metadata for each group.

For each participant group, extract the following fields (use null if not mentioned):
- sample_size: number of subjects
- condition: disease or condition studied (e.g., COVID-19, healthy)
- cohort: cohort name or geographic location
- assay_method: experimental method or assay used
- tissue_type: tissue or sample type analyzed

Return a JSON array of objects, one per participant group, each with the fields: group_id, group_name, sample_size, condition, cohort, assay_method, tissue_type.

Example input:
Participant Group 0: Healthy individuals from Atlanta
  - we evaluated cytokines and chemokines in plasma samples from the Atlanta cohort using the Olink multiplex inflammation panel
  - compared to healthy subjects
  - n = 18 healthy

Example output:
[
  {
    "group_id": 0,
    "group_name": "Healthy individuals from Atlanta",
    "sample_size": 18,
    "condition": "healthy",
    "cohort": "Atlanta",
    "assay_method": "Olink",
    "tissue_type": "plasma"
  }
]

Return ONLY valid JSON — no markdown, no explanation.
