Only a pairing the ontology itself made counts: the same term (MATCH), or one term a parent or child of the other (MATCH GRANULARITY). A row paired by a shared name or quote carries a different or missing term, so CONFLICT and UNMAPPED count toward recall and not here — that gap is the 3 rows between the two tiles.

Strict mode: both denominators are the 59 rows the curators wrote. A curated row left without a partner is MISSED even when another row on the same term was paired, and the 0 pairs the ontology alone made were taken only after every pair the names made.

What each arm is
agent (this page)
The pipeline these results come from: six rounds — three extraction calls voted into one registry, a verifier, a corrector, the OBI mapping, a fold on measurement identity, and a judge for the folds the rules refused. The mapping step retrieves 30 candidate terms by embedding and spends one call picking among them, reading their definitions. ~17 model calls per paper.
bare LLM, ids as given
One call per paper: “list this paper's assays and give each an OBI id”, with no vocabulary in the prompt. Scored on the ids the model produced, which it has to recall from memory — this is what an ontology id looks like when nothing checks it. Mean of three runs.
bare LLM, labels read
The same three runs, scored more kindly: the model's *labels* are resolved to OBI ids for it, so the arm is judged on whether it named the right assay rather than on recalling the number. The gap between this column and the one before it is pure id recall.
RAG single call
Retrieval-augmented generation in its simplest form: the same one-call prompt, but the whole 701-term OBI vocabulary is pasted into the context, so the model picks ids off a list instead of recalling them. One call per paper — no vote, no verifier, no fold. This is the “just put the ontology in the prompt” baseline, and the closest arm to the agent. Mean of three runs.
OntoGPT
The published tool (SPIRES, v1.2.0) for exactly this task, run as it ships on the same model: the LLM extracts entities, then OAK grounds each string to OBI by lexical lookup. One call per paper.
NCBO Annotator
BioPortal's concept-recognition web service over OBI — no model at all, pure string recognition of OBI labels and synonyms in the text. The established non-LLM tool.
dictionary
Our own no-model control: OBI labels and synonyms matched against the paper, longest match first, plurals and a trailing “assay” handled. It exists to show how much of the score is available from string matching alone.
agent, old fold
The same agent registries under the superseded fold rule (“same OBI term ⇒ same assay”). Not a competitor — it is here to price the current rule, which keeps one entry per measurement instead of per technique.
